## 📌 Project Overview

The **Date & Time Utility Library + Event Scheduler** is a C++ menu-driven application developed using Object-Oriented Programming (OOP) concepts. The project allows users to create, manage, search, and delete events while also providing current system date and time information.

The project is designed to demonstrate the practical implementation of classes, objects, constructors, modular programming, and date & time handling in C++.

---

## ✨ Features

- Menu-Driven Interface
- Add New Event
- View All Events
- Search Event by Title
- Delete Event
- Display Current Date & Time
- DateTime Class
- Event Class
- Object-Oriented Programming (OOP)
- Simple and User-Friendly Console Interface
